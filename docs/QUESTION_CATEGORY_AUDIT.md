# Question category audit (2026-10-21)

Every question in the live `questions` table (417) was read against the rubric for its current category. **165 are flagged as a poor fit.** Unflagged questions were judged an acceptable fit. Suggested categories are proposals for review, nothing has been changed in the database.

`General / Open-ended` is a proposed new category: questions that are legitimate interview questions but fit none of the 8 formats (e.g. "How do you prefer to receive feedback?"). It would use a flexible rubric (relevance, specific evidence, reasoning, clarity) instead of a framework.
